Statistical analysis of oceanographic data (Black Sea – Danube area)

This project aimed to understand how environmental conditions influence species distribution. Using oceanographic data, I applied statistical analyses (normality tests, clustering, PCA, biodiversity indices) to identify spatial patterns. Results showed that nutrient-rich, silty environments near the Danube support higher biodiversity, while more distant sandy areas host different communities.The complete script is available below.

Skills acquired:

  • Statistical analysis (Shapiro test, data transformation)

  • Biodiversity indices (Shannon, Simpson, evenness)

  • Multivariate analysis (PCA, clustering)

  • Distance metrics (Bray-Curtis, Hellinger, Chord)

  • Data visualization (maps, dendrograms, PCA plots)

  • Ecological data interpretation (species–environment relationships)

## 4. Biodiversity Indices
#Several biodiversity indices were calculated to describe species diversity at each #station:
#- Species richness (N0)
#- Shannon index (H)
#- Hill numbers (N1, N2)
#- Evenness indices (J, E1, E2)

N0 <- rowSums(data_spc > 0)
H <- diversity(data_spc)
N1 <- exp(H)
N2 <- diversity(data_spc, "inv")
J <- H/log(N0)
E1 <- N1/N0
E2 <- N2/N0

div1 <- data.frame(N0, H, N1, N2, E1, E2, J)
div1

Biochemistry and Physiology of Marine Animals (Collaborative Project)

This academic project explores the biochemistry and physiology of marine animals, focusing on the adaptations of blue-ringed octopuses (genus Hapalochlaena). It examines their evolutionary origins, habitat distribution, feeding strategies, reproductive behavior, and advanced camouflage systems. Particular attention is given to their unique use of tetrodotoxin (TTX), a powerful neurotoxin used for both predation and defense. This work highlights how morphological, physiological, and behavioral traits are finely tuned to environmental constraints.

Skills acquired:

  • Scientific research and literature review

  • Data synthesis and critical analysis

  • Academic writing in English

  • Team collaboration

  • Marine biology and biochemistry knowledge

  • Oral and written scientific communication
